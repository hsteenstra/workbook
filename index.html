Code, Program & Syntax

Before anything else - the words programmers throw around, defined in plain English.

Definition

Code - written instructions that tell a computer what to do, written in a language it understands (like Python).

Definition

Program - a complete set of code that does something useful when it runs, start to finish. A game is a program. So is a calculator.

Definition

Programming - the act of writing code to build a program. That's what you're learning.

Definition

Syntax - the exact spelling, punctuation, and grammar rules of a language. Miss a colon or a quote mark and Python won't understand you, even if a human would.

Think Of It Like...

Syntax is like spelling and grammar in English. "I are hungry" is understandable to a person but wrong. Python is far less forgiving than a person - one missing symbol and it refuses to run at all.

YOU WRITE CODE  ->  PYTHON READS IT  ->  PYTHON RUNS IT  ->  SOMETHING HAPPENS
   (syntax matters here) ^
Remember

Python runs your code top to bottom, one line at a time, unless something (like a loop or a function) tells it to jump around.

Bonus: Comments

A comment is a note in your code that Python completely ignores - it's for humans, not the computer. Start one with #.

# this line does nothing when the program runs
print("Score:", score)  # this part is a comment too

Use comments to remind future-you why a tricky line exists. You don't need many yet - just know the symbol when you see it.

print() - Talking to the Screen

Definition

print() is a built-in Python function (a reusable action) that displays text or values on the screen.

  YOUR CODE            PYTHON PROCESSES IT         SCREEN OUTPUT
print("Hello!")   ------------>  runs  ------------>   Hello!

Syntax

print("some text")

The parentheses () hold what you want to print. Text must be wrapped in quotation marks - this makes it a string (see p12).

print("Score:")

Forgetting quotation marks around text:

print(Hello)   # ERROR - Python thinks Hello is a variable name

Fix: print("Hello")

Forgetting a closing parenthesis:

print() - More Ways To Use It

Printing multiple things with commas

Separate items with commas - Python automatically puts a space between them.

score = 10
print("Score:", score)   # Score: 10

Printing numbers directly (no quotes needed)

print(5)
print(5 + 2)     # 7  - Python does the math first

f-strings - building a sentence with variables inside

Put an f right before the opening quote, then wrap a variable in { } to drop it into the sentence.

name = "Ava"
score = 42
print(f"{name} scored {score} points!")
# Ava scored 42 points!
Think Of It Like...

An f-string is a fill-in-the-blank sentence. The { } are the blanks; Python fills them in with whatever the variable holds right now.

Variables - The Labeled Box

Definition

A variable is a name that stores a value so you can use it later. Value just means "a piece of data" - a number, some text, etc.

Think Of It Like...

A variable is a labeled storage box. The label is the variable name. Whatever you put inside is the value. You can look inside anytime, and you can swap out what's inside later.

score = 100

+-------------+
|   score     |   <- the label (variable name)
+-------------+
|    100      |   <- what's inside (the value)
+-------------+

Changing what's in the box

score = 100
score = 150
BEFORE                 AFTER
+-------------+        +-------------+
|   score     |   ->    |   score     |
+-------------+        +-------------+
|    100      |        |    150      |   <- old value is gone, overwritten
+-------------+        +-------------+
Remember

In Python, = means "store this value in this box," not "equals" like in math class. It's called assignment. To check if two things are mathematically equal, you use == (see p23).

String - What Is Text Data?

Definition

A string (str) is text - any sequence of characters wrapped in quotation marks. Letters, numbers, symbols, spaces - all of it counts as a string once it's in quotes.

Think Of It Like...

A string is like beads on a string (that's actually where the name comes from) - each character is a bead, threaded in order.

Examples (strings)Not examples
"hello"hello (no quotes - Python treats this as a variable name)
"42"42 (no quotes - this is an integer)
"Game Over!"True (this is a Boolean)
"" (empty string - still a string!) 

How to create one

message = "You win!"
player_name = "Jordan"
Where You'd Use This

Games: player names, messages ("Game Over"), item names. Visual coding: labels, color names passed to turtle like "red".

Common Mistake 
score = "10"
total = score + 5   # ERROR - "10" is text, not a number

Python has no idea how to add a number to text. This is the #1 beginner string bug.

Strings: Quotes & Joining

Single vs. double quotes

Python doesn't care which you use, as long as you start and end with the same kind.

greeting = 'Hello'
greeting = "Hello"     # identical to Python
Remember

Use double quotes when your text contains an apostrophe: "it's a trap". Using single quotes there ('it's a trap') breaks the string early.

Concatenation - joining strings with +

first = "Ava"
last = "Chen"
full = first + " " + last
print(full)      # Ava Chen
Common Mistake

Forgetting the space string in between -> "AvaChen". The + doesn't add spaces for you.

Repeating strings with *

line = "-" * 10
print(line)     # ----------
Where You'd Use This

Building a divider line, repeating a character for a loading bar, stacking a player's name onto their score in one printed line.

String Indexing

Definition

Indexing means grabbing one character out of a string by its position number. Python starts counting positions at 0, not 1.

            "PYTHON"

         P    Y    T    H    O    N
         0    1    2    3    4    5     <- index numbers
word = "PYTHON"
print(word[0])     # P
print(word[2])     # T
Remember

Square brackets [ ] after a variable = "give me the character at this position." Counting starts at 0. This trips up every beginner at least once - it's not just you.

Common Mistake 
word = "PYTHON"
print(word[6])   # ERROR - index out of range

The last valid index is length - 1. "PYTHON" has 6 letters, so valid indexes are 0-5.

Negative Indexing & len()

Python also lets you count backward from the end, using negative numbers. -1 is always the last character.

            "PYTHON"

         P    Y    T    H    O    N
        -6   -5   -4   -3   -2   -1    <- negative index numbers
word = "PYTHON"
print(word[-1])    # N  (last letter)
print(word[-2])    # O  (second to last)
Definition

len() returns how many characters are in a string (its length).

word = "PYTHON"
print(len(word))    # 6
Remember

len(word) - 1 always equals the index of the last character. That's why word[-1] is such a handy shortcut - no counting required.

None - The Empty Value

Definition

None is a special value meaning "nothing, on purpose." Its type is NoneType. It is not 0, not an empty string, not False - it's the absence of a value entirely.

Think Of It Like...

An empty inventory slot isn't "zero items sitting there" - it's a slot with nothing assigned to it yet. That's None.

winner = None       # no winner yet
selected_item = None

if winner is None:
    print("Game still going")
Remember

Compare to None using is None, not == None. Not required to know why yet - just the habit to build now.

Where You'd Use This

A "current target" variable before the player selects an enemy. A "high score" before any score has been recorded. A function that hasn't returned anything yet.

Common Mistake

Confusing None with 0 or "". All three are "falsy," but they mean different things - 0 is a real number, None is the absence of one.

Remember

Change one thing at a time. If you change five things and it works, you'll never know which change actually fixed it - and you might have added a new bug.

Reading a Python error

Python errors usually tell you the exact line number and a short description at the bottom. Always read the last line of the error first - that's the actual problem.

Debugging Checklist

Work through these, in order, before asking for help.

Checklist
  • [ ] Did I read the last line of the error message?
  • [ ] Did I find the exact line number it points to?
  • [ ] Are all my colons, quotes, and parentheses matched up?
  • [ ] Is my indentation consistent (same number of spaces)?
  • [ ] Did I spell every variable name exactly the same everywhere?
  • [ ] Am I mixing up = and ==?
  • [ ] Is a string sneaking in where I need a number (or vice versa)?

How To Read Code - Tracing Variables

Definition

Tracing means running code in your head (or on paper), line by line, writing down what every variable equals after each line. It's the single best skill for both debugging and predicting output.

Trace this by hand - fill in the table as you go:

y = x - y
print(x, y)
Linexy

Remember

Read the right side of an = first - Python always fully calculates it before storing anything.

When To Trace

Whenever output doesn't match what you expected. Draw a mini table like the one above, one column per variable, one row per line - the wrong value usually reveals itself immediately.
